# محفظة إبراهيم سمير — دليل مبسّط بالعربي

المشروع ده موقع بورتفوليو فيه لوحة تحكم (Admin) لإدارة الأعمال والمحتوى.

## ⚠️ قبل أي حاجة: غيّر بيانات دخول الأدمن

افتح ملف `.env.example`، انسخه وسمّيه `.env`، وحط فيه بريد وباسورد جديدين
في `ADMIN_EMAIL` و `ADMIN_PASSWORD`. الباسورد القديم كان مكتوب في الكود القديم،
فلو مستخدمينه لسه غيّروه فورًا.

## أسهل طريقة تشغّل بيها الموقع فعليًا (Live) من غير أي أوامر برمجية

### 1) قاعدة البيانات (مجانية)
- روح على https://neon.com وسجّل حساب مجاني
- أنشئ مشروع جديد، وهيديك رابط اسمه Connection String (شكله زي
  `postgresql://user:pass@host/dbname`) — احتفظ بيه، هتحتاجه بعدين

### 2) رفع الكود على GitHub (بالماوس، من غير أوامر)
- سجّل دخول على https://github.com (أو اعمل حساب لو مالكش)
- اضغط زرار "New repository" وسمّيه أي اسم (مثلاً `ibrahim-portfolio`)
- خليه **Private** لحد ما تتأكد إن كل حاجة شغالة
- بعد ما يتعمل الريبو، هتلاقي رابط "uploading an existing file" —
  اضغط عليه واسحب كل ملفات المشروع (ما عدا مجلد node_modules لو موجود)
  وارفعها

### 3) النشر (Deploy) على Vercel (مجاني)
- روح على https://vercel.com وسجّل دخول بحساب الـ GitHub بتاعك
- اضغط "Add New Project" واختار الريبو اللي رفعته
- في خطوة الإعدادات (Environment Variables) ضيف:
  - `DATABASE_URL` = الرابط اللي جبته من Neon
  - `AUTH_SECRET` = أي نص عشوائي طويل (مثلاً 40 حرف/رقم مخلوطين)
  - `ADMIN_EMAIL` = البريد اللي عايز تدخل بيه
  - `ADMIN_PASSWORD` = باسورد قوي من اختيارك
- اضغط Deploy واستنى شوية، هيديك رابط للموقع شغال أونلاين

### 4) الدخول على لوحة التحكم
- افتح `الرابط-بتاع-موقعك/admin/login`
- سجّل دخول بالبريد والباسورد اللي حطيتهم في `ADMIN_EMAIL` / `ADMIN_PASSWORD`

## ملاحظة
أول مرة الموقع يفتح، هو بيعمل تجهيز تلقائي لقاعدة البيانات (بيانات تجريبية:
أعمال، تصنيفات، خدمات...) — تقدر تعدلها أو تمسحها من لوحة التحكم بعدين.
